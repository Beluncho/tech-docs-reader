# Visual Mapper: визуальный маппинг таблиц

Руководство пользователя. Visual Mapper — визуальный редактор для сложных таблиц
паспортов (матрицы «модель × параметр», объединённые ячейки, многострочные шапки),
которые не разбираются обычными наборами извлечения.

Идея: вы видите таблицу как в Excel и размечаете ячейки **человекочитаемыми ролями**
(модель, параметр, значение…), а система по этой разметке извлекает данные.
Готовая разметка сохраняется как **шаблон** и автоматически подхватывается
похожими таблицами в других документах.

---

## Когда использовать

| Ситуация | Инструмент |
|---|---|
| Обычный паспорт, пары «метка: значение» | Набор извлечения (конструктор «Настроить набор») |
| Матрица «модели × параметры», rowspan/colspan, нестандартная шапка | **Visual Mapper** |
| Новая сложная таблица, шаблона ещё нет | **Visual Mapper** → 🤖 «Предложить маппинг» (LLM разметит черновик) |
| Разовая проверка, документ не типовой | «Извлечь через LLM» |

## Открытие

1. Загрузите документ и выберите его в списке слева.
2. Нажмите **🎨 Визуальный маппинг** в тулбаре документа.
3. В верхней панели выберите таблицу. По умолчанию открывается самая большая.
   Метка `📌 шаблон` у таблицы означает, что для неё найден сохранённый шаблон
   (наведите курсор — увидите имя).

Подсказка: в превью документа рамки таблиц показывают их id; рамки таблиц
с шаблоном подписаны именем шаблона (tooltip).

## Разметка ролей

1. Выделите ячейки:
   - **клик** — одна ячейка;
   - **протяните** — прямоугольный диапазон;
   - **Ctrl+клик** — добавить/убрать ячейку;
   - **Shift+клик** — расширить диапазон.
   Клик по «продолжению» объединённой ячейки выделяет её целиком.
2. Нажмите кнопку роли в панели «Роли» (цвет ячеек изменится):

| Роль | Что означает | Пример |
|---|---|---|
| 🏷️ Модель | Название изделия/модели — по одной карточке на модель | НС 13-70 |
| 📊 Параметр | Название характеристики | Подача |
| 🔢 Значение | Значение параметра | 70 |
| 📏 Единица | Единица измерения (если не в тексте параметра) | м³/ч |
| 📂 Секция | Заголовок раздела — группа параметров | Гидравлика |
| 💬 Условие | Примечание/условие к карточке | для 2522 |
| 🚫 Игнорировать | Исключить ячейку из извлечения | |

3. Поля «Название параметра / Единица / Группа» (под кнопками ролей) переопределяют
   тексты ячеек: например, для rowspan-параметра «Подача, м³/ч (13)» можно задать
   чистое название «Подача» и единицу «м³/ч».
4. Ошиблись — **↶ Отменить** (Ctrl+Z), **↷ Повторить** (Ctrl+Y). «Снять роль с
   выделения» убирает роль с выбранных ячеек (тоже откатывается).

## Структурные правки

Если детектор распознал структуру неточно (разрезал логическую ячейку, лишние
строки/колонки, таблица «лежит на боку») — исправьте перед разметкой:

- **⬜ Объединить** — слить выделенные ячейки в одну (тексты складываются);
- **🔲 Разделить** — вернуть объединённым ячейкам исходный размер;
- **🔄 Транспонировать** — поменять строки и колонки местами;
- **− Строки / − Колонки** — удалить строки/колонки выделения.

Все правки попадают в общую историю с ролями и откатываются вместе.

## Предпросмотр

Кнопка **👁️ Собрать предпросмотр** показывает, что именно будет извлечено:
карточки моделей с параметрами, статистика и предупреждения
(значение без параметра, несколько значений у одного параметра и т.п.).
Расчёт идёт на сервере (единая семантика с backend), при недоступности API — локально.

Предпросмотр сбрасывается при любом изменении ролей/структуры — просто соберите заново.
**⬇ JSON** выгружает разметку + результат, **⬇ CSV** — результат таблицей
(`model;param;value;unit;group;condition`).

## Шаблоны

Разметка (роли + структурные правки) сохраняется как **шаблон** и привязывается
к структуре таблицы (число колонок + тексты шапки), а не к конкретному документу.

- **💾 Сохранить шаблон** (или Ctrl+S) — имя по умолчанию `<файл> — <таблица>`;
- при открытии таблицы похожей структуры появляется баннер
  «Найден шаблон: «…» (точное совпадение / сходство N%)» с кнопкой «Применить» —
  шаблон **не** применяется автоматически, только по вашему клику;
- список шаблонов: «→» — применить к текущей таблице, «✕» — удалить;
  несовпавшая структура — не ошибка: не подошедшие роли пропускаются
  (в статусе — сколько).

Применённый шаблон можно доработать и сохранить под тем же именем (перезапишется)
или новым.

## LLM-ассистент

Кнопка **🤖 Предложить маппинг** отправляет таблицу в LLM, который размечает роли
по её структуре (занимает ~10 сек, стоит ~2₽). Используйте, когда таблица новая
и шаблона для неё ещё нет. Подробно (спорные клетки, кэш, стоимость, ограничения) —
в [LLM_ASSISTANT.md](./LLM_ASSISTANT.md).

- Предложение **заменяет текущие роли** — если у вас уже есть разметка,
  появится подтверждение. Откат — **Ctrl+Z** (одно действие истории).
- Клетки, в которых LLM не уверен (confidence < 0.7), подсвечиваются жёлтой
  рамкой и перечисляются в панели. Сводка в панели: сколько ролей уверенно /
  спорно, какая модель отвечала и сколько времени заняло.
- Спорную клетку можно поправить **прямо в списке**, не ища кнопку роли:
  под каждым непроверенным пунктом — кнопки альтернативных ролей
  («→ Параметр 40%») и «✓ верно» (роль LLM правильная, оставить). Пункт можно
  также кликнуть — клетка выделится на канвасе, дальше штатные кнопки ролей.
- Исправление одной клетки **не стирает список** остальных спорных: пункт
  помечается «✏️ исправлено», рамка с проверенной клетки снимается, в сводке
  виден прогресс «проверено X/N». Полный сброс панели — при структурных
  правках, смене таблицы или возврате к полностью своим ролям.
- Пустой ответ («не нашёл, что размечать») — таблица, по мнению LLM, не
  подходит для извлечения; роли не меняются.
- Ваши исправления (какой роли вы предпочли предложение LLM) автоматически
  записываются в журнал на сервере — он используется для улучшения промптов
  и для метрики точности (`GET /api/llm/metrics`).
- Ответы кэшируются на сервере: повторное предложение **той же таблицы**
  приходит мгновенно и бесплатно (в сводке будет «📦 из кэша»). После правки
  промптов кэш обновляется сам.
- После правки предложения можно сразу **💾 Сохранить шаблон** — тогда похожие
  таблицы размечаться LLM больше не будут (шаблон применится автоматически).

Кнопка недоступна, если LLM не настроен на сервере (нет ключа API) или если
в таблице есть структурные правки (объединение/транспонирование/удаление):
координаты предложения считаются по исходной сетке таблицы. Предложите маппинг
до правок или верните структуру (Ctrl+Z).

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z) | Отменить / повторить |
| Ctrl+S | Сохранить шаблон |
| Esc | Закрыть маппер |
| Ctrl+колесо | Зум |

При переключении таблицы или закрытии маппера с несохранёнными ролями
появится предупреждение.

## Ограничения

- Маппинг работает по таблицам детектора: если таблица найдена плохо
  (разрезана, лишние куски), сначала исправьте структуру правками —
  они войдут в шаблон и воспроизведутся на похожих таблицах.
- Шаблон подбирается по структуре: у похожей таблицы должны совпасть число
  колонок и шапка (точно, либо сходство ≥ 75%).
- LLM-ассистент не работает при структурных правках таблицы (координаты
  предложения — по исходной сетке) и требует настроенного ключа API на сервере.
